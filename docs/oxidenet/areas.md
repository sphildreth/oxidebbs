# OxideNet Areas

Default areas:

| Tag | Purpose |
| --- | --- |
| `OXIDE.GENERAL` | General public discussion. |
| `OXIDE.SYSOP` | Sysop-to-sysop operations and help. |
| `OXIDE.NETWORK` | Network announcements, policy updates, and routing notices. |
| `OXIDE.TEST` | Test posts and first-poll validation. |

Config package import creates local echomail areas using lowercase keys such as
`oxide-general` and subscribes them to the matching network areas.
