# OxideNet Policy

Policy version `1.0` is the default accepted policy for OxideNet packages.

Members must:

- run a reachable BinkP endpoint for their assigned node;
- keep the generated session password private;
- avoid duplicate, spam, or abusive echomail traffic;
- honor `OXIDE.NETWORK` announcements from the hub;
- accept suspension while routing, credential, or conduct issues are resolved.

The hub stores policy acceptance on the application and config package. Policy
version updates are handled by issuing a new config package after review.
